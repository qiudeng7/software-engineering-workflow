# CONTRIBUTING 参考问题

目标读者是准备进行第一次贡献的开发者。将问题改写为当前项目中的一次真实改动，不附预期答案。

- 去哪里查找或提出任务，哪些变更需要先讨论？
- 怎样建立开发环境，哪些配置或凭据需要另行获取？
- 对本次类型的修改，需要运行哪些检查？在哪里执行，怎样判断通过？
- 检查失败或缺少某项运行环境时，应怎样处理和报告？
- 应如何提交变更，PR 需要哪些说明或证据？
- 哪些规则是强制要求，哪些只是建议？后续如何进入评审？

例如，“我只修正文档链接，需要做哪些验证？”和“我修改数据库结构，需要额外做什么？”可以检查验证要求是否与风险对应；只选择项目实际存在的场景。

公共安装说明可以链接 README。审阅者应检查整条贡献路径是否可找到，不要求在两份文件里重复写一遍。不得因常见开源习惯而猜测项目的分支、提交或审批规则。
