# README 参考问题

目标读者是第一次接触项目的潜在使用者。按项目实际功能选择问题，主 Agent 送审前替换泛称，不附预期答案。

- 这个项目解决什么问题，什么情况下适合我使用？
- 第一次使用需要哪些环境、权限或依赖？
- 从准备到完成最小操作，应按什么顺序执行？
- 成功后应看到什么结果，怎样判断已经跑通？
- 哪些限制或风险会影响我的选择或操作？
- 需要更多配置、开发或排障信息时，到哪里找？

例如，对于 SVG 绘图工具，可以问“收到生成文件后，我怎样查看和继续修改它？”而不是“它是不是可以直接在浏览器打开？”

审阅时尝试连贯说明最短使用路径，识别缺失前置条件或依赖作者解释的跳步。完整 API 和架构细节可以通过链接找到，不要求 README 收纳全部内容。
